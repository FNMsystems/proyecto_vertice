El proyecto consta de una plataforma educacional, esta es la mejora de proyectos mas conocidos como libros digitales para establecimientos educacionales, la diferencia es que este busca mejorar integrando:
1. Retiro de Alumnos
2. Certificados
3. Justificativos medicos
4. Áreas especificas según rol dentro de la institución
5. Mejora de procesos como matriculas, Intenciones de Matricula entre otros.
